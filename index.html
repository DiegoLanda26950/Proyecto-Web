Tecnologías Clave

Terraform

Infraestructura

Es una herramienta de Infraestructura como Código (IaC) creada por HashiCorp. Te permite definir, aprovisionar y administrar servidores y servicios en la nube de forma segura y consistente usando archivos de configuración declarativos.

Amazon S3

Almacenamiento

Es el servicio de almacenamiento de objetos líder de Amazon Web Services (AWS). Está diseñado para guardar y recuperar cualquier cantidad de datos de forma altamente segura, escalable, económica y con una durabilidad extrema.

MCP

Protocolo IA

El Model Context Protocol es un estándar abierto desarrollado por Anthropic. Funciona como una conexión segura e inteligente bidireccional entre modelos de IA y bases de datos o herramientas, dándoles contexto en tiempo real.
